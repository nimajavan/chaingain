# Security Policy

## Launch status

LottoChain is pre-production and unaudited. Do not send real tokens to any
development or test deployment. A deployed address is not considered official
unless it is published by the project and its source is verified on TRONSCAN.

## Reporting a vulnerability

Report suspected vulnerabilities privately through this repository's GitHub
Security Advisory feature. Do not open a public issue containing exploit details,
private keys, wallet recovery phrases, or personal information.

Include the affected commit or contract address, network, impacted function,
reproduction steps, expected impact, and a minimal proof of concept when safe.
Do not test against Mainnet accounts or funds you do not own.

## Response expectations

Reports will be triaged by severity. Acknowledgement and remediation timelines
will be published before Mainnet launch together with the final disclosure and
bug-bounty policy.
